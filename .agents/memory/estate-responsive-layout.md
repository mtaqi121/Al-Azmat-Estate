---
name: Estate dashboard responsive layout
description: Responsive design constraint for the AL-AZMAT ESTATE property dashboard.
---

Treat the available content width after navigation as the hero’s layout constraint. Collapse the fixed rail before the hero copy and artwork compete for space, and keep WhatsApp reachable in both navigation modes.

**Why:** Preview checks at medium widths exposed hero overlap and cramped copy when the sidebar reduced the page’s usable width.

**How to apply:** When changing the sidebar or breakpoints, recheck hero copy, imagery, and contact actions at desktop, tablet, and mobile widths.
